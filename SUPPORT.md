# Support

| You want to | Go to |
|---|---|
| learn how to deploy and write services | the docs: https://21-ci.github.io/runtime/ and the [samples](sample/README.md) |
| ask a question or share an idea | [GitHub Discussions](https://github.com/21-ci/runtime/discussions) |
| report a bug | a [bug report](https://github.com/21-ci/runtime/issues/new?template=bug_report.yml) with the version (`rt --version`, `21ci --version`) and steps to reproduce |
| propose a feature | a [feature request](https://github.com/21-ci/runtime/issues/new?template=feature_request.yml) |
| report a vulnerability | **not** an issue: follow [SECURITY.md](SECURITY.md) |
| let your coding agent write services | the agent skills in [skills/](skills/) |
| reach the project (partnerships, press, anything else) | contact@21ci.uz |

Support is best effort from the maintainers and the community. Only the latest minor release gets fixes (see the
supported versions in [SECURITY.md](SECURITY.md#supported-versions)), so please check that a bug still reproduces on
it before reporting.
