21 Cloud packages

Signed package repositories for rt (the runtime node, deb/rpm) and 21ci (the CLI, deb/rpm/apk). Source: github.com/21-ci/runtime. Docs: 21-ci.github.io/runtime.

Debian / Ubuntu

curl -fsSL https://21-ci.github.io/runtime/packages/gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/21cloud.gpg
echo "deb [signed-by=/etc/apt/keyrings/21cloud.gpg] https://21-ci.github.io/runtime/packages/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/21cloud.list
sudo apt update && sudo apt install rt 21ci

Fedora / RHEL / openSUSE

sudo curl -fsSL -o /etc/yum.repos.d/21cloud.repo https://21-ci.github.io/runtime/packages/rpm/21cloud.repo
sudo dnf install rt 21ci

Alpine (21ci only)

wget -qO /etc/apk/keys/21cloud.rsa.pub https://21-ci.github.io/runtime/packages/apk/21cloud.rsa.pub
echo "https://21-ci.github.io/runtime/packages/apk" >> /etc/apk/repositories
apk add 21ci

rt needs glibc (prebuilt V8); on Alpine run the image ghcr.io/21-ci/rt.

Verify the key

The GPG key fingerprint is listed in SECURITY.md. Compare it with gpg --show-keys gpg.key before you trust the repository.
